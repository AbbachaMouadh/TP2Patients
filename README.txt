PATIENTS APP - TP 2 (Retrofit + MVVM) - complete Android Studio project

HOW TO OPEN
  Android Studio -> File -> Open -> choose THIS folder ("Patients", the one that
  contains settings.gradle.kts). Wait for the Gradle sync to finish.
  If Android Studio asks to download an SDK or update something: accept.

BEFORE RUNNING
  - Start the TP 1 API: npm run dev (port 5000)
  - Emulator: nothing to change.
  - Real phone: edit BASE_URL in di/AppContainer.kt AND the IP in
    res/xml/network_security_config.xml.
